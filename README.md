# LE MANAGER HUB
## The Global Music Industry Hub

**Talent • Brand • Opportunities • Community**

Le Manager Hub is a global music-industry ecosystem connecting artists, managers, producers, promoters, labels, media, venues, brands, businesses, entertainment professionals, and fans.

## Vision
Build a trusted global connection point where the people, talent, businesses, media, fans, events, and opportunities that drive the music industry can discover one another, collaborate, and grow.

## Core Platform
- Global professional and artist directory
- Artist and professional profiles
- Companies and organizations
- Opportunities marketplace
- Events and live experiences
- Professional booking network
- Le Manager TV
- Le Manager Radio
- Le Manager Podcast
- Music and industry news
- Verification and memberships
- Le Manager Fans
- Le Manager Event Squad

## Two Connected Communities
### Industry
Artists, managers, producers, songwriters, promoters, booking agents, labels, distributors, publicists, lawyers, DJs, studios, media professionals, creators, venues, brands, sponsors, and other entertainment professionals.

### Fans
Music fans, concertgoers, fan clubs, supporters, ambassadors, and members of the Le Manager Event Squad.
